### DESCRIPTION
**Hopely** is an antivirus software prototype that combines machine learning algorithms, AI-based analysis, and dynamic analysis via a local virtual machine.

### KEY FEATURES
* AI Analysis: **Multi-stage AI-driven analysis.**
* Dynamic Analysis: **The software deploys a local virtual machine, allowing for the monitoring of a program's actions within a secure environment.**
* Analysis of Executable (.exe) Files: **Currently subject to limitations; future versions will remove these restrictions and expand support to include additional file formats.**
* Report Generation: **Produces clear, well-formatted reports.**

### TECHNICAL IMPLEMENTATION
* Language: **Written in Python.**
* Libraries: **Utilizes pefile, math, yara-python, os, capstone, json, subprocess, psutil, and scikit-learn.**
