"""Hopely — антивирусное ПО на основе эвристического анализа.

Пакет разбит на модули по этапам алгоритма из проекта:

    config      — конфигурация и ключи (.env, переменные окружения)
    models      — структуры отчётов, которые общие для всех модулей
    static      — экспресс-анализ: PE-структура (pefile) и YARA-правила
    dynamic     — песочница: изолированный запуск и перехват активности
    ai          — ИИ-анализ итогового отчёта
    scoring     — жесткие логические фильтры и подсчёт риска
    pipeline    — оркестратор, соединяющий модули в один проход
    cli         — командная строка
"""


init - начальная инициализация

main - задача точки входа

config - конфигурация hopely {
Делится на модули:
1) задаем константы для работы кода
2) вытаскиваем ключ из .env, чтобы не вытаскивать ключи из кода, а безопасно вытащить из окружения
3) задача параметров ИИ-анализа. Вытаскиваем ключи из блока номер 2 и инициализируем их
4) Параметры песочницы для динамического анализа. Делаем повышенную защиту
5) задаем все настройки для запуска сканера

}

models - структура данных, чтобы собрать их ответ в красивый json. делится на модули {
1) задание функции джсона
2) смотрим совпадения с правилами YARA
3) составляем итоги прогона через правила YARA.
4) результат сканирование песочницей
5) вердикт от ИИ
6) Полный отчет

}

static - крпупный блок анализа. делится на {
init - статистический экспресс анализ
pe_module - крупный модуль, который вскрывает PE-заголовки. состоит из {
1) ввод библиотеки pefile
2) задача инъекций кода и машины
3) статистический разбор pe-файла - утилиты:
	подсчет энтропии Шеннона (0.0-8.0) и вовзарещние кодировки файла
	сканирование, которое в случае чего выведет точную причину ошибки сканирования
	просмотр секций и дизассемблер для наглядности
4) сбор подорзительных импортов и библиотек
5) подсчет подозрительных импортов
}

yara_module - крупный модуль, который компилирует текстовые правила из rules/ и прогоняет байты файла через них {
1) ввод библиотеки yara и возврат, если правила не скомпилироваллись
2) прогон файла по yara-правилам. состоит из утилит {
	загрузка - чтение всех файлов из каталога правил
	сканирование - прогон байтов через правила, возвращаеми список YaraMatch
	привод - доводим метаданные правила к словарю и проверяем работу
	ИИ - компилируем временные правила, например от ИИ и прогоняем байты 
}
}

}

dinamic - крупный модуль, отвечающий за изолированный запуск и перехват активности {
init - контролируемый запуск файла и перехват акивности
sandbox - изолированный запуск файла. Так как проект только на первой стадии, то пока мы используем песочницу на мощностях windows. Конечно, это повышает безопасноть, но гарантий не дает. {
1) ввод библиотеки psutil
2) задаем константы и классы для имитации работы ОС
3) проводим контролируем запуск файла. классы {
	проверка подписей - проверяем подписи для начала работы
	запуск - перед полной инициализацей, проверяем остановлены ли все библиотеки и ОС. дальше идет аналих процессов и подстраивание под файлов. скормлю ии агенту сам сделает

}

telemetry - сбор данных о поведении файла и спорных маркеров {
1) ввод библиотеки psutil
2) начало наблюдения - утилиты {
	смотрим за процессом и всеми его потомками
	собираем множество метрик и другую очень полезную информацию. дам ии агенту сам допишет
}

}
}
}

ai - ИИ анализ итогового отчета {
init - запуск анализа
analyzer - крупный модуль, отвечающий за сбор отчета. состоит из утилит {
	построение - даем иишке контекст и только значимые факты
	вызов - пытаемся вызвать ии и даем ему
	разбор ответа - разбираем ответы и упаковываем в json
}

client - анализ итогового отчета без сторонних SDK. здесь мы пытаемся вызвать иишку ну и так по промту. короче мне лень напишет ии агент
}

scoring - жесткие логические фильтры и подсчет риска {
здесь мы переводим все собранные данные в баллы риска. думаю дам ИИ агенту дописать эту историю...
}

pipeline - скрипт, который соединяет модули в одно. {
думаю написанием этого блока тоже займется ииагент...
}

cli - командная строка {
короче ии агент допишет
}
